# AETHER Editor — desktop milestone

The editor is a separate desktop host sharing the runtime and project format. Dear ImGui's docking branch is the UI foundation; ImGuizmo and imgui-node-editor supply scene manipulation and visual-graph widgets.

Planned workspace: central scene/game viewport; left hierarchy; right inspector; bottom asset browser, console and profiler; top play/pause/step and target selector.

This repository includes the panel scaffold under editor/src/. It is not yet a complete desktop editor. The Android APK in this milestone is the native game runtime/showcase, not a touch-based scene editor.
